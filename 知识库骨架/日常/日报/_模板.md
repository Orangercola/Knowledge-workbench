# YYYY-MM-DD 工作日报（星期X）

> **填表说明**：日报不是流水账，是周报的素材。每天只做一件事——把当天工作填进「与周报对齐的主题」段落。周末汇总时，把一周 5 天相同主题的段落直接合并，周报第一章节就成型了。
> **铁律**：写"推进了什么 / 完成了什么 / 卡在哪"，不写"几点干了啥"。

## 一、重点工作（按主题，与周报对齐）

### 主题一（示例：某业务线名称）
- 对接XX，完成XX，推动XX。子事项：① ② ③

### 主题二
- 配合XX部门，完成XX。

### 主题三
- ① 需求方A：事项 + 进展 + 卡点
- ② 需求方B：事项 + 进展 + 卡点

### 主题四 / 主题五
- ...

### （新增主题：直接加，周报汇总时并入对应块）
- ...

## 二、其他工作
- 杂项、会议、跨部门协同等（不需要展开叙述的）

## 三、明日计划 / 待跟进
- 对应周报「下周重点工作」的种子，写"计划推进什么"

## 写作要点

1. **主题名与周报对齐**，不要每天换叫法。同一件事在日报里叫「需求对接」，在周报里叫「供需对接」，汇总时就得人工合并。
2. **卡点必须写出来**。「推进中」不是状态，「等对方反馈方案」「资质未批」才是。
3. **数字要落纸**。数量、金额、进度百分比，能写就写。周报的「指标逐周更新」全靠日报攒。
4. **不写时间流水**。「上午开会下午写材料」对周报没有任何价值。
5. **生活待办不进日报**，那是日常页的事。
