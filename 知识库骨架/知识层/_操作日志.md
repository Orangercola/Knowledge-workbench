# 操作日志

> **追加式**：只允许在文件末尾新增行，永不修改、永不删除已有行。这是审计知识库演进的唯一凭证。

## 格式

```
[YYYY-MM-DD HH:MM] 操作类型 | 简短描述 | 涉及文件
```

**操作类型**：`ingest`（摄入）、`query`（查询）、`lint`（审计）、`fix`（修复）、`archive`（归档）、`restructure`（重构）

## 约定

- 描述要能让人半年后看懂「当时做了什么、为什么做」，不要只写「更新页面」
- 涉及文件写相对路径，多个用顿号分隔；批量操作写数量 + 代表文件
- 定时任务空跑也要留一行（`ingest | 定时扫描无新增文件 | -`），便于判断任务是否还活着
- 批量改动建议用脚本幂等追加（先 grep 该行是否已存在），避免重跑产生重复记录
