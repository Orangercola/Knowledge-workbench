# 活动名称

> **一句话定位：** 什么活动、谁办、为什么办、服务什么目标

（2~4 句引言：活动的背景与定位，为什么值得记录沉淀）

## 📋 筹备
- **目标 / 主题**：活动要达成什么
- **时间 / 地点 / 规模**：预期时间、场地、参与人数
- **组织分工**：主办 / 承办 / 协办方及各自职责
- **物料与资源**：场地、设备、物料、预算
- **关键时间节点**：倒排计划（里程碑）

## 🎬 过程
- **议程 / 流程**：环节顺序与时长
- **现场记录**：各环节要点、发言摘录
- **现场数据**：实际到场人数、互动量、产出物

## 📣 宣传
- **传播渠道**：公众号 / 媒体 / 内部渠道
- **宣传物料**：推文 / 海报 / 视频 / 通稿
- **传播效果**：阅读量、曝光量、转发量（可后补）

## 📊 总结
- **成效与亮点**：达成目标的情况、出彩之处
- **问题与不足**：暴露的短板、教训
- **经验沉淀**：可复用的打法、SOP
- **待办 / 后续动作**：遗留事项、下一步
