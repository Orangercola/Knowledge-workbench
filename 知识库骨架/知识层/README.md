# 知识层/ — 第二层

> 本层是知识库的核心，由 **AI 全权维护**。人负责审查、定方向、提要求。

## 用途

- 把 `原始素材/` 的原料提炼为结构化、双向链接的知识页面
- 持续维护总索引、路由表、全局综述与操作日志
- 按主题领域组织知识（见 `主题/`）

## 写入规则

- **谁可以写**：AI 代理（人也可直接编辑，但必须遵循同样规范）
- 页面必须基于 `_模板/` 中的模板创建
- 必须填写完整 YAML frontmatter：`type` / `title` / `tags` / `created` / `updated` / `aliases` / `source` / `confidence` / `review`
- 必须用 `[[双向链接]]` 关联相关页面，**禁止孤立页面**（新页至少链 2 个已有页）
- 每次新增 / 修改，向 `_操作日志.md` **末尾追加**一条记录
- 批量更新后，同步刷新 `_总索引.md` 与 `_全局综述.md`

## 目录结构

| 路径 | 内容 | `type` 值 |
|---|---|---|
| `_总索引.md` | 总索引（自动维护，按类型分节） | — |
| `_操作日志.md` | 操作日志（追加式，永不删除） | — |
| `_全局综述.md` | 全局综述（一页看全库） | `overview` |
| `_路由表.md` | 任务 → 页面直达映射（≤12 条） | `router` |
| `_模板/` | 页面模板 + 关系类型标签规范 | `template` |
| `素材摘要/` | 单篇素材摘要页（一篇素材一页） | `source` |
| `概念/` | 概念页（方法 / 理论 / 技术 / 模式） | `concept` |
| `实体/` | 实体页（人物 / 公司 / 产品 / 组织 / 项目） | `entity` |
| `对比/` | 对比分析页 | `comparison` |
| `综述/` | 综合论述 / 深度分析页 | `synthesis` |
| `活动/` | 活动记录（筹备 / 过程 / 宣传 / 总结） | `event` |
| `提示词/` | 可复用提示词主库 | `prompt` |
| `随笔/` | 阅读笔记 | `essay` |
| `主题/` | 按领域分类，每个主题一个 `_索引.md` | `topic` |

## 页面状态字段

| 字段 | 取值 | 含义 |
|---|---|---|
| `review` | `pending` / `done` | AI 产出默认 pending，人确认后改 done |
| `confidence` | `high` / `medium` / `low` | 依据权威性与交叉验证；拿不准标 low |
| `deprecated` | `true` / `false` | 废弃标记。**绝不删除页面**，只标废弃 |
| `reingest` | `done` | 被「打回重写」后置位，表示已重写待验收；验收通过后由工作台清除 |

## 与其他层的关系

- 输入：读取 `原始素材/` 与 `AI研究/`（只读）
- 输出：按需生成报告到 `输出/报告/`（临时产物不留在本层）
