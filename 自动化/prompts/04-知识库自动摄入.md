# 📥 知识库新文件自动摄入

| 项 | 值 |
|---|---|
| 触发 | 每 12 小时（00:30 / 12:30） |
| 规则 | `FREQ=HOURLY;INTERVAL=12` |
| 场景 | 扫业务素材区的新文件，转成转换稿、编译进知识层、更新索引和操作日志。这是整个知识库的「自动落库」环节。 |

## 设计要点

- 先读 AGENTS.md 主控 Schema 再动手 —— 把规范放在文件里，prompt 只负责调度，规则升级不用改任务。
- 安全红线写在 prompt 里：业务素材区只读、绝不删文件、拿不准标 confidence: low。
- 「活动/实体聚类与吸纳」那条最值钱：新素材若是旧活动/旧实体的续篇，必须补进主页面并双向挂链，而不是又建一个孤立页。
- 没新文件时只追一行日志就结束，不推送长篇报告。

## Prompt

> 使用前把 `{知识库根}` 换成自己的知识库路径。

```text
执行知识库新文件自动摄入任务。知识库根目录：{知识库根}（先读该目录下 AGENTS.md 主控 Schema 并严格遵守，含 2026-08-07 新增的「图片素材特别规则」与 2026-08-15 新增的「活动/实体聚类与吸纳规则」）。

任务目标：找出知识库中「尚未处理」的新增文件，按 ingest（摄入）流程处理并编译进知识层。

扫描范围（仅这两处的新文件）：
1. 业务素材区 V1.1/ 及其全部子目录（制度文件/案例材料/汇报材料/省级平台/平台手册 等 22 个目录）——只读，AI 禁止写入，原始文件绝不动
2. 原始素材区 原始素材/ 下各子目录（文章/论文/逐字稿/数据/随手笔记/图片/附件）

判定「未处理」的标准：业务素材区的文件在 原始素材/文章/ 下没有对应的「<文件名>-转换稿.md」；原始素材区新增的 md 若尚未在 知识层/ 编译出对应页面也需摄入。注意：知识层/ 已编译过的素材（在 知识层/素材摘要/ 或实体/概念/对比/综述有同名/同源页面）跳过。

转换规则（按 AGENTS.md 工具路由表，禁止新装任何包）：
- 图片（png/jpg/jpeg/webp）：用 RapidOCR（python 环境 {Python 环境}，rapidocr_onnxruntime）提取文字，多张同组图片合并为一份转换稿。**图片素材特别规则（双路并行，缺一不可）**：① 原图同步复制到 原始素材/图片/，按命名规范 yyyy-mm-dd-图片内容描述.png（如 2026-08-07-平台手册-画板1.png）；② OCR 转换稿照常写入 原始素材/文章/<名>-转换稿.md；③ 素材摘要页 source 中同时标注原图路径与转换稿路径
- docx/xlsx/pptx/pdf：用 markitdown（同一 python 环境）转换
- .doc 老格式：markitdown 不支持则跳过并在日志登记（勿装 LibreOffice）
转换稿统一写入 原始素材/文章/，开头标注「> 原始文件：<相对路径>」。

摄入编译（AGENTS.md 操作1：摄入）：
- 每个新文件识别核心主题（1~3 个），先查 知识层/_总索引.md 和 知识层/_路由表.md
- 主题存在 → 更新该主题索引页和对应知识层页面（素材摘要/概念/实体/对比/综述按内容类型）
- 主题不存在 → 在 知识层/主题/ 创建新主题目录和 _索引.md，并更新 _总索引.md
- 新建的素材摘要页必须：frontmatter 含 type: source、review: pending、confidence、source 指向转换稿（图片素材还要加原图路径）；正文含「**来源：**」行、2~4 句引言、## 核心要点、## 相关链接（3~8 个 [[双向链接]]）、## 待澄清问题（有疑问才写，绝不编造）；新页面至少链接 2 个已有页面
- **【强制】活动/实体聚类与吸纳（源于活动复盘断链事故）**：建独立 素材摘要 页之前，必须先检索 知识层/活动/（按活动名/别名匹配）与 知识层/实体/（按同名实体），判断本文件是否为某已有页面的子素材/续篇（如某活动的签到表、复盘、宣传稿、课件、手册）。命中已有活动/实体页 → 必须「吸纳」：把新文件实质内容补写进主页面对应段（活动页补 筹备/过程/宣传/总结 或新增「复盘与改进」段；实体页补 运营数据/时间线），并在主页面 ## 相关链接 与 元信息/相关资料 补入本 source 的 [[双向链接]]，同时本 source 页 ## 相关链接 必须回链主页面；未命中 → 才新建独立 素材摘要 页。该检查无条件执行，不得因「已建 source 页」而省略回链与吸纳。每次摄入若有命中，在 _操作日志 注明「已吸纳至 <主页面>」。详细规则以 AGENTS.md 操作1「活动/实体聚类与吸纳规则」为准。
- 更新对应主题 知识层/主题/<主题>/_索引.md、知识层/_总索引.md（数量统计+清单）、知识层/_路由表.md（如需）
- 每笔操作在 知识层/_操作日志.md 追加一行：[YYYY-MM-DD HH:MM] ingest | 简短描述 | 涉及文件

安全红线（绝对遵守）：
- 绝不写入业务素材区（V1.1 和根目录业务目录）——原始文件只读
- 原始素材/图片/ 中的图片文件：AI 可新增（摄入同步原图），但绝不修改/删除已有图片
- 绝不删除任何文件
- 拿不准的论断标 confidence: low，写进待澄清问题
- 本次运行没有新文件时，在 知识层/_操作日志.md 追加一行「[时间] ingest | 定时扫描无新增文件 | -」后正常结束，不要向用户推送长篇报告

完成标准：所有新文件都有转换稿（图片同时有原图同步）+ 知识层页面 + 索引日志同步（活动/实体续篇素材须吸纳进主页面并双向挂链）。最后用 3~5 句话总结本次处理了哪些文件、产出哪些页面、有什么待办。
```
